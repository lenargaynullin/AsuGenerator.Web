# AsuGenerator 🚀
> **Коммерческий B2B SaaS-сервис для автоматического проектирования и расчета спецификаций шкафов автоматизации (НКУ / ЩУВ / ШУЭ)**

[.NET 10](https://microsoft.com)
[Blazor](https://microsoft.com)
[Docker](https://docker.com)
[Nginx](https://nginx.org)

**AsuGenerator** — это высокопроизводительная облачная платформа, разработанная для полной автоматизации рутинного труда инженеров-проектировщиков, сметчиков и тендерных специалистов электрощитовых производств при формировании спецификаций и коммерческих предложений (КП).

**Продакшен-версия сайта:** [https://asugenerator.ru](https://asugenerator.ru)

## 🏗️ Архитектура и паттерны проектирования

Бэкенд платформы спроектирован с упором на слабую связанность компонентов и высокую расширяемость.
Добавление новых типов шкафов (стратегий расчета) происходит без изменения существующего кода домена (соблюдение принципа Open-Closed из SOLID).

*   **Паттерн «Стратегия + Фабрика» (`ICabinetStrategy`):** Изолирует вычислительное ядро расчета. Фабрика динамически на лету разрешает нужную стратегию подбора на основе конфигурации пользователя.
*   **Высокопроизводительный In-Memory поиск:** Оптимизированы операции работы со словарями и хэш-таблицами с помощью методов `TryGetValue`, что устраняет двойное сканирование (double-hashing) и минимизирует аллокацию памяти под высокой конкурентной нагрузкой [📡].
*   **Декларативный Rule-Based движок:** Правила подбора оборудования вынесены в динамические JSON-конфигурации (`shuv-strategy.json`), полностью отделяя бизнес-логику от C#-кода.

## ⚡ Ключевые технические фичи

1.  **Умное ГОСТ-сжатие позиций (Regex):** Реализован алгоритм постобработки текстовых строк с использованием регулярных выражений для автоматического свертывания последовательных индексов аппаратуры в диапазоны (например, автоматическая трансформация длинных массивов в формат `QF1...QF13`) с корректным суммированием общего штучного количества.
2.  **Контекстно-зависимое связывание аксессуаров:** Разработан механизм сквозного маппинга родительских и дочерних компонентов. Системные суффиксы в JSON (`_Socket`, `_Clip`, `_Led`) на лету трансформируются в привязанные физические позиции (например, «Колодка для KL1»), строго наследуя порядковый индекс родительского реле [📡].
3.  **Реактивная матрица многоканальных линий:** Разработан кастомный интерактивный интерфейс таблицы отходящих линий для шкафов электрообогрева (ШУЭ) до 13 независимых каналов с динамической подстановкой силовых аппаратов и защитных дифов на основе параметров цепи.
4.  **Движок расчета физических габаритов:** Интегрирован модуль вычисления заполняемости DIN-реек и перфорированных кабель-каналов. Система автоматически агрегирует общую длину оборудования, рассчитывает необходимый конструктив корпуса и маппит результат на реальный каталог металлоконструкций (IEK серии ЩМП).

## 💻 Технологический стек

*   **Backend Core:** C# 12 / .NET 10.0 (Primary Constructors, Collection Expressions, Strict Nullable Reference Types).
*   **Frontend UI:** Blazor Web App (Interactive Server Circuit) + библиотека компонентов MudBlazor [📡].
*   **Отчетность:** Модуль автоматической генерации электронных таблиц ClosedXML для моментального скачивания спецификаций в формате `.xlsx` [📡].
*   **DevOps и Инфраструктура:** 
    *   Виртуальный сервер VDS под управлением Ubuntu Server.
    *   Docker (Многоэтапная многослойная сборка Multi-stage build для оптимизации размера рантайм-образа).
    *   Веб-сервер Nginx в роли Reverse Proxy с настроенными правилами WebSocket-проксирования (кастомные заголовки `Upgrade $http_upgrade` для удержания стабильности Blazor-сессий).
    *   Безопасность: Автоматическое обновление SSL-сертификатов через Certbot (Let's Encrypt).

## 🐳 Быстрый старт и локальный запуск

Для локального развертывания проекта или деплоя на чистую ноду Linux убедитесь, что у вас установлен Docker, и выполните команды:

```bash
# Клонирование репозитория
git clone https://github.com
cd AsuGenerator

# Сборка Docker-образа
docker build -t asugenerator-image .

# Запуск контейнера в фоновом режиме с автоперезапуском
docker run -d -p 5000:8080 --name asugenerator-app --restart always asugenerator-image
```
Приложение станет доступно на хост-машине по адресу: `http://localhost:5000`.
